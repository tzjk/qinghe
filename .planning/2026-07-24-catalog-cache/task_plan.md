### 本轮硬性约束

- Redis Key 仅为 `qh:cache:*` 和 `qh:lock:cache:*`，不携带手机号、Token 或密码；Redis 及 MySQL 均不由本轮配置或脚本改写。
- 数据库是事实来源；缓存读取、锁和序列化异常均降级查询 MySQL，数据库查询失败不写缓存。
- 管理员写操作仅在事务成功提交后失效缓存，失效失败仅记录日志，不能回滚已成功的数据库写入。
- 正常缓存 TTL 为配置基础值加受限随机抖动，空值使用独立短 TTL；不把 `null` 作为普通 JSON 缓存。
- 只运行直接店铺、商品和缓存测试；不运行全量测试或前端构建。整个里程碑未完成前不提交、不推送。
