# 购物车商品图片修复计划

## 目标

修复购物车商品实际图片未显示的问题，保持购物车其他业务逻辑不变；不提交、不推送、不执行数据库写操作。

## 阶段

1. **Git 与上下文核查** — complete
2. **图片数据链路排查** — complete
3. **最小范围修复与测试补充** — complete
4. **后端、前端验证与安全审计** — complete
5. **计划与结果记录** — complete

## 约束

- 当前已在 `develop`，但存在用户已有未跟踪规划目录；不切换、不拉取、不重置、不清理、不暂存。
- 只改购物车商品图片相关代码与本计划目录；不执行 SQL 写入或导入。
- 若需数据库核对，仅提供安全 SELECT 语句，不自动连接或执行写操作。
- 完成后不 commit、不 push。

## 验证目标

- 购物车相关 Maven 测试、全量 Maven 测试、前端生产构建均如实记录。
- `git diff --check` 通过，且无敏感信息、构建产物或无关改动。

## 错误记录

| 错误 | 处理 |
|---|---|
| 初始前端补丁未能匹配受编码影响的一行压缩模板 | 未覆盖文件；改用完整、等价的单文件模板重写，保留原有购物车交互与布局。 |
| 指定购物车 Maven 测试在主源码编译阶段读取本地 Jackson JAR 时出现 `Access is denied` | 测试断言尚未运行；将以完全相同命令申请一次受控重试。 |
| 受控 Maven 重试启动 Spring 测试上下文时 Redis 数据库 2 认证失败：`NOAUTH Authentication required` | 主/测试源码均已编译，`CartIntegrationTest` 业务断言未运行；不修改 Redis 或配置，不将此记为通过，且不提前运行全量 Maven 测试。 |
| 前端生产构建首次被沙箱阻止 esbuild 读取目录，Vite 配置未加载 | 将以相同 `npm run build` 命令申请一次受控重试。 |
| 后端全量 Maven 测试未执行 | 用户规定仅在专项测试通过后执行；专项测试被 Redis `NOAUTH` 在断言前阻塞，故不改变顺序或伪造全量结果。 |
