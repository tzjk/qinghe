# 青禾校园智能助手：进入实现前待确认问题

以下问题需要用户/产品/后端负责人确认；未确认前不应开始 FastAPI 实现或修改现有 Spring Boot/Vue3。

1. 一期是否只覆盖当前用户端，明确拒绝任何管理员聊天能力？本设计默认“是”。
2. 允许的模型供应商、部署区域、数据保留政策和预算上限是什么？是否允许将脱敏对话发送给外部模型？
3. FastAPI 服务的部署地址、TLS/反向代理、CORS 精确来源、网络可达的 Spring Boot 基址和服务鉴权方式是什么？
4. 前端是否接受新的 `VITE_AGENT_BASE_URL`、SSE 连接与用户隐私提示？是否需支持匿名公共问答？
5. “今天优惠”的产品定义是否仅指当前可领取券，还是还包含未来的商品/店铺促销活动？需要采用哪个时区及展示口径？
6. 是否批准新增商品关键词搜索、商品促销模型、店铺优惠聚合、默认地址专用接口及用户券店铺名字段？这些字段的权威计算规则由谁定义？
7. 商品级优惠需要哪些字段：原价、活动价、开始/结束时间、适用商品、库存、优先级、叠加规则和展示文案？在未定义前必须保持不可回答。
8. 是否有已批准的校园生活指南、宿舍规章、优惠券规则、配送说明和 FAQ？每份资料的所有者、版本、生效日、有效期、访问权限和更新流程是什么？
9. RAG 是否必须私有部署？向量库、嵌入模型与索引数据的保存位置、删除期限、备份和审计责任如何规定？
10. 会话状态是否需要跨设备/跨登录保留？若需要，独立存储选型、加密、TTL、删除机制和用户可见控制是什么？
11. 坐标隐私策略是否确认：仅用浏览器一次性授权的坐标请求附近商铺，不落库、不写日志；拒绝时由用户显式选校区中心？
12. 工具超时、速率限制、最大消息长度、单会话模型预算、可接受 P95 延迟和熔断阈值各是多少？
13. 401/403 的前端体验是否复用现有 Axios 跳转，还是 Agent API 返回可恢复的结构化事件？
14. 未来写操作的二次确认由 Vue3 还是 FastAPI 生成和保存？无论选择哪方，Spring Boot 是否会在执行时重新校验确认摘要、身份、状态和幂等键？
15. 是否批准在 Phase 1 安装 Python 依赖、创建虚拟环境和创建 `agent-service/app`、`tests`、`.env.example`、`pyproject.toml` 等运行骨架？本阶段尚未做这些动作。
