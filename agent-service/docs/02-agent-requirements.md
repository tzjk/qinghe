# 青禾校园智能助手：需求与业务能力矩阵

## 产品定位

青禾校园智能助手是面向当前登录用户的只读校园服务 Agent。它负责理解自然语言、选择受限工具、解释来自 Spring Boot 的实时结果；不直接连接青禾业务 MySQL，不读写业务 Redis，不自行判定用户身份，也不执行任何写操作。

一期禁止自动下单、支付、领取券、修改订单/宿舍/学生资料或删除数据。未来写工具必须改为“操作预览 → 用户二次确认 → Spring Boot 后端执行”，且确认令牌与操作摘要必须由后端重新校验。

## 能力矩阵

| 用户意图 | 示例问题 | 所需数据 | 当前已有接口 | 登录 | 当前可实现 | 缺失字段或接口 | 推荐工具 | 风险 | 后续建议 |
|---|---|---|---|---:|---|---|---|---|---|
| 今日优惠 | 今天能领什么券？ | 券状态、领取窗口、库存、店铺 | `GET /api/coupons` | 否 | 是 | 无“今日活动”聚合文案 | `get_today_promotions` | 低 | 明确表述为“当前可领取券”，显示服务端时间口径。 |
| 优惠商品 | 哪些商品正在打折？ | 原价、促销价、窗口、适用规则 | 无 | 否 | 否 | 商品没有促销字段；券不关联商品 | `get_discounted_goods` | 中 | 增加商品促销模型或只提供“店铺券可用商品”专用接口。 |
| 商铺搜索 | 找一家咖啡店 | 关键词、分类、营业状态 | `GET /api/shops` | 否 | 是 | 无 | `search_shops` | 低 | 为结果保留分页和无结果提示。 |
| 商品搜索 | 搜索打印纸 | 商品名称/描述关键词 | 无关键字查询 | 否 | 部分 | `GET /api/goods` 无 keyword | `search_goods` | 低 | 新增用户端只读商品关键字查询。 |
| 附近商铺 | 我附近有什么店？ | 经纬度、半径、分类、距离 | `GET /api/explore/shops/nearby` | 否 | 是 | 需浏览器授权坐标 | `get_nearby_shops` | 中 | 不记录精确坐标；拒绝定位时让用户选校区中心。 |
| 我的优惠券 | 我的券还有哪些能用？ | 当前用户券、券规则、状态 | `GET /api/coupons/mine` | 是 | 是 | 结果未提供店铺名称 | `get_my_coupon_wallet` | 中 | 后端可补充 `shopName`，Agent 不猜测。 |
| 我的订单 | 最近订单到哪了？ | 当前用户订单、明细、状态 | `GET /api/orders`、`GET /api/orders/{id}` | 是 | 是 | 无 | `get_my_recent_orders`、`get_my_order_detail` | 高 | 按需返回并脱敏收货信息。 |
| 我的宿舍 | 我住在哪个寝室？ | 当前用户入住、学生档案、床位 | `GET /api/student/dorm/me` | 是 | 是 | 无 | `get_my_dorm_info` | 高 | 不接收任何他人身份参数。 |
| 宿舍规则问答 | 晚归怎么办？ | 经审核的规章资料 | 尚无知识库 | 视内容 | 否 | 正式规章资料、版本/生效日 | `search_dormitory_rules` | 中 | 先建立人工审核、版本化 RAG 语料。 |
| 系统使用帮助 | 怎么查看订单？ | API/页面/使用说明 | Markdown 文档可策展 | 否 | 部分 | 文档清洗与检索索引 | `search_system_help` | 低 | 仅回答已收录资料；引用标题与版本。 |

## 需求约束

- 不允许模型决定或传入当前用户 ID；个人工具的身份来自转发到 Spring Boot 的 Bearer Token。
- 实时事实（券、价格、库存、店铺状态、订单、宿舍）必须每次经 Spring Boot 工具获取，不进入向量库作为答案事实来源。
- 公共工具可以匿名调用，个人工具必须要求用户 Token；Agent 自身的访问控制不能替代 Spring Boot 的权限检查。
- 模型只可调用固定白名单中的只读工具；每个工具均使用 Pydantic 输入/输出模型验证。
- 每个回答必须区分“实时工具结果”“知识库说明”“缺少数据，无法确认”，禁止补全业务事实。
