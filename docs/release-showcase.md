# V1.0 展示材料

## 软件功能说明

青禾校园生活服务系统面向校园生活场景，提供验证码登录、资料与校园地址、店铺商品浏览、购物车、订单、优惠券、探店互动和后台运营管理。系统还包含学籍、宿舍入住、资产套装二维码、订单状态提醒与营业报表，方便进行本地演示和业务流程展示。

## 简历项目描述

独立完成 Spring Boot + Vue 3 校园生活服务系统，覆盖用户端消费链路、管理员运营链路与学籍宿舍资产管理；使用 MyBatis-Plus、MySQL、Redis、Redisson、WebSocket，完成 147 项后端集成回归与前端生产构建。

## 技术亮点

- Redis Hash Token 与用户/管理员上下文隔离。
- 订单支付、取消和超时扫描使用条件更新保证状态竞争下的一致性。
- 普通券采用 MySQL 事务与唯一约束；秒杀券采用 Lua、Redis Stream、Pending 恢复和最终数据库兜底。
- Cache Aside 覆盖店铺、商品和店铺商品列表，含空值缓存、TTL 和提交后失效。
- WebSocket 在事务提交后推送订单事件，HTTP 查询始终作为状态真源。
- 金额使用 `BigDecimal`，客户端不可信任金额、库存、状态或用户 ID。
- 宿舍资产采用床位资产套装、二维码令牌和入住唯一约束。
