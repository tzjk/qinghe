# V1.0 人工浏览器验收清单

使用独立的普通用户与管理员账号，在本地启动已部署的前后端后逐项勾选。不得在地址栏、截图或日志中暴露完整 Token、密码或二维码令牌。

| 验收项 | 预期结果 | 勾选 |
|---|---|---|
| 验证码登录与退出 | 可登录；错误或过期验证码被拒绝；退出后受保护页返回登录 | [ ] |
| 用户资料与地址 | 仅可读写本人资料和地址；默认地址规则正确 | [ ] |
| 店铺、商品与购物车 | 仅展示在售数据；金额、库存和用户身份均由服务端确认 | [ ] |
| 普通订单 | 从购物车创建、查看本人订单、模拟支付与取消均正确 | [ ] |
| 普通优惠券 | 可领取；重复领取得到明确提示；下单、支付、取消后的券状态正确 | [ ] |
| 超时订单 | 超过支付期限的待支付订单自动取消，库存和优惠券状态一致 | [ ] |
| 秒杀优惠券 | 仅活动券走秒杀入口；重复、无库存和过期结果明确 | [ ] |
| 管理员订单流转 | 管理员可接单、配送、完成；普通用户不能访问后台 | [ ] |
| WebSocket 通知 | 用户只收到自己的订单通知；管理员只收到后台订单通知；刷新后以 HTTP 为准 | [ ] |
| 营业报表 | 日期范围、排行、金额及空数据展示正确 | [ ] |
| 学籍、宿舍、入住与资产 | 学籍/入住隔离；二维码只用于本地受保护流程；资产套装与床位状态一致 | [ ] |
| 权限拒绝 | 用户不能访问他人订单、地址、优惠券、学籍或宿舍资料；管理员与普通用户会话不互认 | [ ] |

验收结论：`[ ] 通过  [ ] 有阻断项（记录项号与复现步骤）`
