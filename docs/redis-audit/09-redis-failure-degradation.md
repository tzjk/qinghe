# 09. Redis 故障与降级审计

| 场景 | 当前 Redis 不可用行为 | 正确降级目标 | 评价 |
|---|---|---|---|
| 验证码 | 写失败捕获为 503；读取失败走基础设施异常 | 快速失败并告警 | 正确，不应绕过验证码 |
| 用户/管理员登录会话 | 登录写/拦截器读失败导致 503 | 快速失败；不允许无 Redis 放行受保护请求 | 正确 |
| 商铺/商品/店铺商品缓存 | `CatalogCache` 读/锁/写异常均数据库回源 | MySQL 回退，配合连接池/限流告警 | 基本正确，缺数据库保护指标 |
| 商品全局列表/分类/优惠券 | 未使用 Redis | MySQL 正常承担 | 无 Redis 降级项 |
| 普通优惠券 | 未使用 Redis | MySQL 事务/唯一约束继续 | 合理 |
| 秒杀 Lua | `DataAccessException` 返回 503 | 关闭秒杀入口；绝不绕过 Redis 直接扣 DB | 正确 |
| Stream 消费 | scheduled 捕获异常并日志；消息无法消费 | 受理端应停止成功承诺或明确“受理待处理”；监控 Pending/堆积 | P1：没有可观测积压与运维告警 |
| 订单超时任务 | Redisson 获取/执行异常结束本轮 | 保留数据库定时扫描作为最终方案；Redis 恢复后继续扫描 | P1：当前任务被 Redis 锁完全阻断；可设计单实例受控降级但不能无条件并发运行 |
| 热榜 | 查询异常 MySQL 排序回退 | 返回 DB 结果 | 正确 |
| GEO | 异常 MySQL 距离计算回退 | 返回 DB 结果，注意规模 | 正确但容量风险 |
| WebSocket | 握手拒绝 | 不建立未认证连接 | 正确 |
| Agent 缓存/限流/会话 | 未接 Redis | 进程内状态继续；重启会丢会话/配额 | 单实例合理，多实例需另行设计 |

## 通用问题

`application.yml` 默认 Redis host 为 `192.168.100.128`，通过环境变量可覆盖，但没有连接/命令超时、TLS、哨兵/Cluster、环境 Key 命名空间或 Redis 持久化策略的仓库证据。历史出现过连接超时并不能由本次静态审计复现；本轮未发起任何网络连接。建议把 endpoint、认证、超时、TLS、DB/namespace 和运维 SLA 放入部署环境与监控，而非写死业务代码。
