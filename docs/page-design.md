## 4. 布局与状态管理

- `UserLayout`：首页、商铺、购物车、订单、优惠券、探店、我的；导航根据登录态显示入口。
- `AdminLayout`：仅 `/admin/**`；侧边菜单仅含后台子路由。
- Pinia 存储用户资料、Token 和登录态；Token 同步至 `localStorage`。
- Axios 请求拦截器读取 Token 并设置 `Authorization: Bearer <token>`；响应收到 401 时清空 Pinia 与 `localStorage`，跳转相应登录页。
- 路由元信息建议包含 `requiresUser`、`requiresAdmin`、`title`。管理员守卫不得以用户端登录态代替管理员认证。
- 首页轮播不维护独立页面或轮播表；`banners` 由 `GET /api/home/summary` 返回的 `is_featured=1` 且 `status=1` 推荐商铺渲染，并按 `sort_order` 排序。
