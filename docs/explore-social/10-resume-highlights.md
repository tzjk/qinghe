# 简历表述边界

可表述为：在 Spring Boot/Vue 校园服务项目中实现 Redis Bitmap 签到、MySQL 事实源单向关注图谱、Set 共同关注缓存、按首次点赞时间的 ZSet 前五展示，以及支持滚动游标、回填、惰性清理和容量治理的关注 Feed。

不得表述为生产级推荐系统、机器学习推荐、消息队列异步架构或已完成真实高并发压测。本阶段没有推荐模型、向量数据库、Kafka/RabbitMQ、CDC、真实 Redis/MySQL 联调或自动 SQL 执行。

Phase 2 后仍只能表述为“完成离线审查与受控联调准备”；在独立 Redis namespace、人工执行迁移和真实接口验收前，不得表述为生产级或已上线能力。
